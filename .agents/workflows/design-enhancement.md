# Design Enhancement

Use this workflow to ensure premium, high-quality front-end execution.

1. **Rich Aesthetics**: Enforce state-of-the-art modern designs. Use highly curated palettes, glassmorphism where appropriate, sleek dark modes, and dynamic background gradients.
2. **Typography**: Ensure global typography uses modern sans-serif fonts (like Inter, Outfit, or Roboto). Avoid generic browser defaults.
3. **Micro-animations**: Add subtle Framer Motion hover animations (e.g. `whileHover`, `whileTap`) and entry transitions (`initial`, `animate`) to interactive elements to make the UI feel alive.
4. **Use Established Tooling**: Stick to standard custom CSS or Tailwind CSS architectures. Do not use ad-hoc inline styling strings unless required for dynamic bounds. Utilize Shadcn-style pure UI wrappers if applicable.
5. **No Placeholders**: If an image is required, either map an existing asset from the `public/` directory or generate one natively with an image generator rather than using blank divs.
