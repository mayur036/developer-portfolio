Lucide React v1.7.0 no longer exports brand icons like `Github`, `Linkedin`, or `Figma`. These were removed from the library.

**Why:** Lucide dropped brand/logo icons from their icon set.
**How to apply:** Use generic icon alternatives (SquareTerminal for GitHub, Link for LinkedIn, Palette for Figma) or install a separate brand icon package.
